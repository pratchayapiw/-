# Vethi Verify v1.0 — ระบบรับ–ส่งและตรวจสอบวุฒิการศึกษา

ต้นแบบ (Prototype) แบบไฟล์เดียว เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งเซิร์ฟเวอร์
(ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และตัวอ่านไฟล์ Excel — SheetJS)

## โครงสร้าง
- `index.html` — โครงหน้า
- `style.css` — ธีมชมพู/แถบสีรุ้งของโรงเรียน + dark mode + รูปแบบหนังสือราชการ A4
- `app.js` — ข้อมูล การจับคู่ การนำเข้าไฟล์ และทุกหน้าจอ

## ฟังก์ชัน
| เมนู | ทำอะไร |
|---|---|
| 📊 Dashboard | ภาพรวมหนังสือ ผลการตรวจ ยอดค้างชำระ |
| 📥 รับหนังสือ | ลงทะเบียนรับ เลขรับอัตโนมัติ · แบบที่ 1 แนบใบรายชื่อ (ดึงรายชื่อจาก CSV/Excel ได้) · แบบที่ 2 ระบุรายชื่อในหนังสือ · เก็บเลขประจำตัวเดิม/ชื่อ/สกุล/วันที่จบ/ระดับชั้น |
| 🔍 ตรวจสอบ | ตรวจอัตโนมัติกับฐานข้อมูล (รหัส, เลขบัตร, ชื่อ-สกุล, วันที่จบ, ระดับชั้น) แล้วยืนยันผลรายบุคคล · เห็นยอดค้างชำระเฉพาะเจ้าหน้าที่ |
| 📤 หนังสือส่งออก | สร้างหนังสือแจ้งผล (รูปแบบหนังสือภายนอก) ออกเลขหนังสือส่ง บันทึกการส่ง · **พิมพ์ / บันทึก PDF** ผ่านเมนู Print ของเบราว์เซอร์ (A4) |
| 🎓 ฐานข้อมูลผู้สำเร็จการศึกษา | นำเข้าไฟล์ ปพ.3 (.xls/.xlsx) ต้นฉบับ หรือ CSV แบบย่อ · เพิ่ม/ลบรายบุคคล |
| 💳 ค่าบำรุงการศึกษา | บันทึกยอดและการชำระรายรายการ · ไม่แสดงต่อภายนอก |
| 🧭 ติดตามสถานะ | ขั้นตอน 4 ขั้น + ประวัติการดำเนินการ (รายการ 🔒 ภายในไม่แสดงต่อภายนอก) |
| 📈 รายงาน | รายเดือน ผลการตรวจ หน่วยงาน ยอดค้าง · คัดลอกเป็น CSV |
| 🌐 หน่วยงานภายนอก | เลขที่หนังสือ + E-mail → OTP 6 หลัก (5 นาที, ใช้ครั้งเดียว, ผิดได้ 5 ครั้ง) → ดูสถานะ/ผลตรวจ · ขอ OTP ใหม่ทุกครั้งที่เข้า · ไม่แสดงค่าค้างชำระ |

เปิดหน้าหน่วยงานภายนอกโดยตรง: `index.html#portal`

## ไฟล์ CSV ฐานข้อมูลผู้สำเร็จการศึกษา
```
รหัสประจำตัว,ชื่อ-สกุล,ระดับชั้นที่จบ,วันที่จบ
09483,นางสาวตัวอย่าง ใจดี,ม.6,31/03/2569
```
เพิ่มคอลัมน์ `เลขบัตรประชาชน` และ `GPA` ได้ · วันที่ใช้ พ.ศ. (dd/mm/yyyy) หรือ "31 มีนาคม 2569"

## ไฟล์ ปพ.3
เลือกไฟล์ → เลือกระดับชั้น (ไฟล์ไม่ระบุ ม.3/ม.6 ในตัว; ถ้าชื่อไฟล์เป็น PP3-2568-6.xls ระบบเลือกให้) → นำเข้า
ระบบอ่านทุกแถวที่มีคำนำหน้าชื่อ + รหัส/เลขบัตร และหาวันที่อนุมัติจบจากบล็อก "อนุมัติ" ท้ายเอกสาร ถ้าไม่พบใช้วันที่ที่กรอก

## ข้อจำกัดของต้นแบบ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ระหว่างเครื่อง
- OTP เป็นการจำลอง (แสดงใน "กล่องอีเมลจำลอง") — ของจริงต้องสร้างและตรวจ OTP ที่เซิร์ฟเวอร์ แล้วส่งผ่านบริการอีเมล
- ไม่มีระบบ Login เจ้าหน้าที่

## ขั้นต่อไปสำหรับใช้งานจริง
ฐานข้อมูลออนไลน์ (เช่น Supabase/PostgreSQL) · Login เจ้าหน้าที่และสิทธิ์ผู้ใช้ · OTP E-mail จริงฝั่งเซิร์ฟเวอร์ (เก็บแบบ hash, จำกัดความถี่) · Audit Log · PDF หนังสือราชการฝั่งเซิร์ฟเวอร์ · QR Code สำหรับติดตามสถานะ
